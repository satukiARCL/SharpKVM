# SharpKVM - C# / WPF による軽量ソフトウェア KVM (GUI 版)

ShareMouse や Mouse without Borders のアーキテクチャを踏襲し、C# (.NET 10 / WPF) と Win32 API で構築した、画面配置ドラッグ＆ドロップ対応のソフトウェア KVM アプリケーションです。

---

## 1. 主な機能と実装ポイント

- **直感的な画面配置 GUI (WPF):**
  - キャンバス上で「自 PC」と「相手 PC」のモニターを **マウスでドラッグ＆ドロップ** して自由に配置。
  - **自動吸着スナップ機能 (Magnet Snap):** 相手モニターを自モニターの「右・左・上・下」に近づけると、ピタッと吸着して配置方向を自動認識。
  - 設定は `%APPDATA%\SharpKVM\layout_config.json` に自動保存・復元。
- **4方向のエッジ検出 & 座標リマッピング:**
  - 右配置: 画面右端 ($X \ge W-1$) ➔ 相手画面左端 ($X = 0, Y = y$)
  - 左配置: 画面左端 ($X \le 0$) ➔ 相手画面右端 ($X = W-1, Y = y$)
  - 上配置: 画面上端 ($Y \le 0$) ➔ 相手画面下端 ($X = x, Y = H-1$)
  - 下配置: 画面下端 ($Y \ge H-1$) ➔ 相手画面上端 ($X = x, Y = 0$)
- **低遅延通信:** TCP (`TCP_NODELAY`) による 13 バイトの固定長バイナリパケット通信。
- **安全脱出ホットキー (Fail-Safe):** 遠隔操作中にいつでも **`ScrollLock`** または **`Pause`** キーを押せば、即座にローカル操作に復帰可能。

---

## 2. 実行ファイル

- **配布用（単一 EXE / ランタイム不要）:**  
  `C:\dev\SharpKVM\publish\SharpKVM.exe`  
  ※他 PC にコピーするだけで動作します。
- **開発ビルド:**  
  `C:\dev\SharpKVM\bin\Debug\net10.0-windows\SharpKVM.exe`

---

## 3. 使い方

1. `SharpKVM.exe` をダブルクリックして起動します。
2. **画面配置:** 相手モニターのカード（緑色）をドラッグして、実際のデスク環境に合わせて左右・上下に配置します。
3. **被操作側 PC:** 「受信待機を開始」をクリックします（ポート 24800 で待機）。
4. **操作側 PC:** 相手の IP アドレスを入力し、「操作送信を開始」をクリックします。
5. 配置した方向の画面端へマウスを突き抜けると、シームレスに相手 PC の画面にカーソルが移動し、キーボード・マウスが共有されます。
